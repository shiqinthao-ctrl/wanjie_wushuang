# PRODUCT_SPEC.md — 《万界无双》当前产品基线

## 产品定位
多英雄、跨世界、Roguelite / Bullet Heaven / ARPG。

核心循环：选择英雄 → 局外配置 → 模式/地图 → 战斗 → 升级三选一 → 进化/融合 → 精英/事件 → Boss → 掉落 → 结算 → 永久成长 → 再挑战。

标准剧情局目标约 20 分钟。

## 当前世界
- ST001 乱世荒原
- ST003 花果妖岭
- ST004 忍界战场

长期世界：ST002 梁山夜寨、ST005 无尽海域、ST006 灵界裂谷、ST007 气武星原、ST008 万界终焉。

## 首发 6 英雄
- H001 赤焰战神：近战火刀 / 炎势
- H002 雷霆猛将：雷枪连锁 / 雷势
- H007 灵猴：棍法分身 / 斗战气
- H010 炎忍：高速爆破 / 炎印
- H012 影忍：暗器残影 / 影印
- H019 气功战士：远程蓄力 / 气能

操作：WASD/方向键移动；Q/E英雄技；Space闪避；R终极；F地图交互；Esc暂停。

## 七模式
- story 剧情
- clear 通关
- endless 无尽
- bossrush Boss Rush
- tower 万界塔
- daily 每日挑战
- abyss 深渊

规则：只有剧情影响章节星；失败0星；无尽不被20分钟旧结算终止；Boss Rush连续8 Boss；塔按永久层数推进；每日按本地日期固定词缀；深渊为高压终局。

## Boss
B001 黄巾巨将、B002 乱世妖师、B003 混沌骑将、B006 牛魔妖王、B008 混世魔猿、B009 炎狱忍王、B010 雷瞬忍王、B011 万影忍王。

Boss已有：三阶段、红圈、直线、扇形、环形、护盾、召唤、缩圈、专属掉落。ST004-03剧情为 B009 → B010 双王。

## Build
局内最多6主动/召唤 + 6被动；技能Lv1–5；主动+被动→进化；进化+进化→融合；部分路线→神话。

真实技能实体包括：投射物、领域、龙卷、黑洞、陨石、环绕物、分身/召唤、镜像、分裂/弹射/穿透。

## 装备
30件模板：EQW001–010、EQA001–010、EQX001–010；随机词条；10套套装；6英雄专属武器；Boss专属掉落与三选一。

## 符文
20枚正式符文，最多3槽，支持进攻/形态/生存/元素/成长与三槽共鸣。

## 宠物
PET001 火灵、PET002 雷狼、PET007 治疗精灵、PET011 招财猫、PET015 镜像精灵。

## 长期成长
英雄Lv1–30、1–6星、5档熟练度、6英雄觉醒、20节点账号天赋、账号Lv1–200、每英雄3套Build预设。

## 存档
3槽、Schema 30、localStorage、旧版本迁移。P0原则：新开发不得破坏旧存档。

## 性能
low / balanced / high 三档，必须限制 enemies/shots/enemyShots/effects/numbers/traps/V2.4技能实体，无尽与深渊不得无限累积。

```text

├─ config
├─ state
├─ combat
├─ systems

```

必须分阶段迁移，不能一次性全重写。
