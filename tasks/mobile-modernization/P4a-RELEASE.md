# 万界无双 P4a：手机地图边缘视野修复

版本：`mobile-next-p4a-20260909`，2026-09-09。

手机竖屏移动到地图边缘时，角色现在保持在屏幕中央，避免被顶部状态栏
和底部技能按钮挡住。地图增加清晰边界，边界外的镜头留白不能进入。
现有三个初始英雄、九种进化形态、十条技能路线和六个羁绊继续保留。
本批不改变战斗数值、存档、关卡规则或旧版入口。
