# G1: 局内英雄进化与技能羁绊

2026-09-08 用户新增玩法方向。本规格是新版新增设计，不是旧版规则迁移。
入口为大厅「进化征途」。以现有首关验证玩法，保留「进入战场预览」作对照。

## 玩家循环

选择三个固定初始英雄之一 -> 杀敌拾取经验 -> Lv.3 选择英雄进化 ->
技能升到 Lv.3 时选择互斥分支 -> Lv.8 且任一技能达到 Lv.3 时觉醒 ->
挑战首领、领取战利品、原子结算 -> 新一局重新搭配。
本轮将“其他英雄”实现为局内演化的新身份，不花金币直接购买进化形态。
进化不回血、不重置冷却，不改变永久英雄等级。熟练度归初始英雄。

| 起点 | 进化身份 | 战斗变化 | 觉醒强化 |
|---|---|---|---|
| 赤焰战神 | 赤龙武圣 | 斩击附带向前火刃，近战突进 | 三道火刃、全周斩击 |
| 赤焰战神 | 焚城炎君 | 环形普攻，技能建立火域并获得限量护盾 | 扩大领域与护盾 |
| 炎忍 | 烈羽凰使 | 扇形火羽弹幕，突进留下火径 | 五道火羽、更长火径 |
| 炎忍 | 焰影统领 | 投刃攻击，技能召出定时协同攻击分身 | 三名分身、延长持续 |
| 影忍 | 虚空行者 | 穿透影刃，技能生成移动牵引风暴 | 更多穿透、扩大风暴 |
| 影忍 | 无间修罗 | 近战环斩，技能突进爆发 | 全周双斩；闪避后追加影刃 |

## 技能和羁绊

九种主动：火球术、火焰领域、龙卷风、陨石雨、烈焰刀、火焰冲刺、雷电弹、
手里剑、影分身。最多六个主动和六个被动，单技能最高 Lv.5。起始携带各英雄
两项主动和一项心法，其余从共用池抽选，允许跨英雄组合。每次普通升级提供
至多三项不重复合法选择；优先留一项已有主动成长机会，保留随机新能力。

| Lv.3 技能分支 | 分支一 | 分支二 |
|---|---|---|
| 火球术 | 连珠：三道扇射、单发较弱 | 爆星：单发更慢、更大的爆炸 |
| 龙卷风 | 游龙：向目标移动、持续牵引 | 环身：围绕角色旋转、防守近身 |
| 影分身 | 游猎：分身跟随，射出追敌影刃 | 守阵：分身驻守，定时范围斩击 |

羁绊以不同已持有技能计数，升级不重复贡献，装备虚拟等级不计。
火球/烈焰刀/火焰领域/陨石雨/火焰冲刺属炎；手里剑/影分身属影；雷电弹属雷；龙卷风属风。

- 风火燎原：至少一炎一风。龙卷风伤害脉冲追加火焰伤害。
- 雷影追猎：至少一雷一影。雷电弹多跳一个目标，Boss 也参与跳链。
- 影火同源：至少一炎一影。成功闪避在起点留下持续燃烧影印。

面板显示技能需求、已有计数和效果。升级选择显示标签与效果；暂停的
「本局路线」展示已得分支和进化条件。伤害由核心执行，不依赖表现事件。

## 工程边界与验证

GameCore 可选 journey 参数启动局内 RunEvolution，默认 classic API、RNG
和顺序保持不变。Phaser 唯一推进规则；新召唤/弹体有限额，销毁时清理。
进化征途使用各英雄默认起始术式及共用候选池；保存的 build 原样保留。
英雄选择只更新新版当前存档 hero，保留其余进度和导入原件。
进化摘要随结算收据保存，下一局始终重新初始化。
进化征途的游商仅提供回复与离开；尚未接入新版伤害规则的旧火力商品不出售，
规则层在付款前拒绝此选项，避免出现花费金币但没有效果的购买。

先验规则，再验真实浏览器自然升级、羁绊和结算。手机模拟尺寸只作浏览器证据。
真机触控、热稳定和平衡体验待测。P2j 原始准备生命耗尽缺口保留。
后续再拓展跨系三阶、永久图鉴、更多英雄、关卡和模式，不宣称未实现内容可玩。
