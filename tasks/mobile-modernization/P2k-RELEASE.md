# 万界无双 Mobile-next P2k 结算诊断检查点

版本标签：`mobile-next-p2k-20260908`，2026-09-08。

本批修正自然战斗测试可能过早结束的问题，增加初始存档逐字段核对，
并在目标未达成时先记录实际结算、奖励保存、刷新存档和再次挑战结果。
每轮录制使用独立目录，已有结果不能覆盖。
导入测试还补上了等待存档面板加载完成的步骤，原始失败记录一并保留。

原始初始配置的自然生命耗尽验收仍未关闭。三个浏览器尺寸采用贴近首领、
不主动释放技能的策略，实际都击败了首领，分别在第 292、297、311 秒结束。
三段的奖励与重开核对通过，但生命耗尽目标保留为失败。54 组合成诊断
产生 21 次胜利、33 次超时，也没有生命耗尽；这不证明自然死亡不可能。

本批不改变 G3 玩法：继续保留三个初始英雄、九个局内进化形态、觉醒、
十条技能路线与六个技能羁绊。游戏规则、数值和准备配置保持原样。

## 下载与查看

- `wanjie-p2k-test-recordings.zip`：解压全部文件，用 Chrome 打开
  `index.html`，可选择录像、跳到实际结算、倍速观看、下载原始录像。
  也可运行 `node serve-report.mjs . 4191`，访问 `http://127.0.0.1:4191/`。
  录像、截图、存档导出、失败断言及合成诊断都随包提供。
- 三个 `fresh-defeat-*.webm`：初始配置生命耗尽目标未达成的原始录像，
  文件名表示测试目标；实际结算为胜利，请勿误读为死亡验收通过。
- `wanjie-p2k-mobile-preview.zip`：包含未改变 G3 玩法的当前构建。
  解压到新目录后托管其父目录，例如运行
  `python -m http.server 4178 --bind 127.0.0.1`，访问
  `http://127.0.0.1:4178/mobile-next/`，大厅选择“进化征途”。
- `SHA256SUMS.txt` 和包内 `MANIFEST.json`：文件大小、校验值及版本来源。
