# 万界无双 Mobile-next G3 开发预览

版本标签：`mobile-next-g3-20260908`，2026-09-08。

本版完善进化征途的战斗辨识与路线选择：雷电沿真实命中路径显示连线，
寒域显示边界与剩余时间，驻守近卫和随行猎手使用不同标记。十条技能路线
说明打法、取舍和互斥分支；羁绊面板列出已拥有与还缺的技能。

暂停菜单增加战斗特效开关，关闭短暂表现后仍保留寒域边界、危险弹道和
经验晶体。本批没有调整伤害、经验、目标顺序、随机规则或敌人生成。

包含此前进度：三个初始英雄、九个局内进化形态、觉醒、十条技能路线、
六个技能羁绊，以及首关战斗、奖励保存和再次挑战。

## 下载与查看

- `wanjie-g3-test-recordings.zip`：解压全部文件，使用 Chrome 打开
  `index.html`，可选路线、跳转关键步骤、倍速和下载原片。也可在解压目录
  使用 Node 22.12+ 运行 `node serve-report.mjs`，访问 `http://127.0.0.1:4190/`；
  随包的播放服务支持视频进度跳转。
- 四个单独的 `.webm` 文件：碎冰、天罚、游猎、守阵的自然操作原速录像。
- `wanjie-g3-mobile-preview.zip`：解压至新目录，以静态服务器托管该目录，
  访问 `/mobile-next/`。例如 `python -m http.server 4178 --bind 127.0.0.1`，
  然后打开 `http://127.0.0.1:4178/mobile-next/`。大厅选择“进化征途”。
- `SHA256SUMS.txt` 与压缩包内 `MANIFEST.json`：核对文件及其版本来源。

## 测试说明

规则测试 946/946；旧版五项检查、49 个基线文件校验、新版类型检查和
构建通过。受影响浏览器回归 87/87 通过，完整结果随包提供，包含合成故障
测试与三条原有进化自然流程。四条最终交付录像单独通过，其中桌面碎冰
完成首领胜利、战利品、奖励保存和重开，战斗结果为 557 击破、Lv.18、三星。

录制尝试共 7 次通过、3 次失败：两次未在步数预算内完成指定羁绊展示，
一次因升级框阻挡自动化脚本退出而超时。退出脚本已修正，所有失败证据
保留，报告列出每次尝试。最终四段录像不等于全部尝试首次通过。

## 存档与回退

新版使用独立 IndexedDB 存储 `wanjie-mobile-next`。旧存档 JSON 复制导入
新槽；旧版原存档保留。不同域名或端口的存档相互独立，迁移地址前先导出。
遇到问题可继续使用原有旧版入口；不提供新版存档自动反向转换。
