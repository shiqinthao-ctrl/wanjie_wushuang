## 原片与检查记录

- `attempt-01/test-results/`：6 个初次桌面场景，修复前原片全部保留。
- `browser-final/test-results/`：24 个修复前桌面/手机场景，可复核提示裁切问题。
- `browser-verified/test-results/`：最终 88 项测试输出，其中包含 56 份有录像的流程原片。
- 每个敌人场景目录包含 `scenario.json`、`response.png`、`video.webm`；非击杀场景另有 `windup.png`。
- 各批 `playwright-report/index.html` 为本地交互报告；`results.json` 保留全部机器可读结果。
- `highlights/` 保存桌面/手机关键帧、场景数据和 MP4 抽帧，便于 GitHub 查看。

`recordings.json` 记录 86 份原片、86 份报告副本、8 份 MP4 的位置、大小、时长和 SHA-256。
全部文件完整解码通过；校验同时检查解码器错误输出和有效时长，没有只依赖退出码。
报告副本不计为额外独立录制，合集也不计为新增测试。

完整视频和 HTML/追踪按现有忽略规则仅保留本地，GitHub 包含源码、结果、关键帧、索引和哈希。
可在项目根目录运行 `node tasks/game-remediation/evidence/R1d/package-evidence.mjs` 重新导出与校验。
