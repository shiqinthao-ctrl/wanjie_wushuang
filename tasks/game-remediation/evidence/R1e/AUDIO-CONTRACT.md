# R1e：表现与声音接入合同

范围为 `chapter1-v1`、H001→赤龙武圣样板，基线 `8505a3d`。
本文件记录已实现的工程行为；外包音效、角色序列帧、音乐与真人听感验收仍待完成。

## 所有权与资源来源

- `chapterPresentation.ts` 的 CH1-GROUND、H001-BODY、EN001-BODY、B001-BODY
  指向项目已有四个 SVG，版本标记 G5；没有新增外部图片或改变既有权属记录。
- H001 仍用已有图片；赤龙继续使用 R1c `DragonView`，武器配色改为读取映射。
  当前没有新增进化立绘、动作序列帧或专业美术验收。
- 16 类声音由本次源代码中的振荡器、频率序列和包络生成，无音源采样、下载音频或第三方素材。
  这是原创程序合成的工程音色，不计入外包 40 项音效或 5 首音乐的交付数量。
- Native Web Audio 管理声音；Phaser 音频管理器保持 `noAudio:true`。
  原因是本次只验证事件、解锁、混音与清理，可在不增加依赖的情况下替换现有静音状态。
  后续接入成品声音时替换 AudioBackend，保持同一声音所有者，避免双重播放与独立战斗循环。

## 音色与核心事件

| 音色 | 事件来源 | 优先级 | 同类间隔/长度（秒） |
|---|---|---:|---|
| hit | 已确认正伤害命中 | 0 | 0.09 / 0.10 |
| basic | H001/赤龙普攻、A003 | 1 | 0.10 / 0.16 |
| kill | 核心击杀事件 | 1 | 0.12 / 0.18 |
| pickup | 经验拾取事件 | 1 | 0.12 / 0.14 |
| dodge | 成功执行闪避的 ring 事件 | 2 | 0.15 / 0.22 |
| windup | 赤龙攻击开始预备 | 2 | 0.15 / 0.12 |
| skill | H001/赤龙主动技释放 | 3 | 0.18 / 0.80 |
| ultimate | H001/赤龙必杀释放 | 4 | 0.60 / 1.10 |
| level | 首次/累计经验进入下一升级选择 | 5 | 0.30 / 0.50 |
| evolve | 接受有效进化选择 | 6 | 0.40 / 0.85 |
| awaken | 接受有效觉醒选择 | 7 | 0.40 / 1.20 |
| victory | 首领击败；另在进入胜利结果时一次播放 | 7 | 0.50 / 1.10 |
| defeat | 进入失败结果时一次播放 | 7 | 0.50 / 0.90 |
| hurt | 玩家实际扣除生命 | 8 | 0.20 / 0.24 |
| boss | 首领登场/转阶段 | 9 | 0.50 / 0.80 |
| warning | 首领开始招式预警 | 10 | 0.25 / 0.45 |

赤龙斩击仅 release 阶段映射攻击声音，预备另用 windup；零伤害、未知来源不播放。
二次音效不产生规则事件，不消费玩法随机数。首领击败音与结果音是两个不同时间节点，
不会用音色播放结束决定胜利，也不会绕过战利品确认。

## 混音与生命周期

同一帧相同音色合并；最多 6 声部，高优先级可抢占最低优先级声部。
优先级至少 8 的危险音存在时，普通声音为当前音量的 25%，危险音结束后恢复。
默认音量 65%，支持 0–100% 与独立静音。短包络避免连续满幅；普通音效允许按预算丢弃。

只在可信 pointerdown/keydown 且页面可见时创建/恢复上下文；未解锁事件直接丢弃。
解锁失败可由下次操作重试，重复请求合并；退出后迟到的异步完成不能重新启用混音器。
窗口 blur 不捕获子元素失焦，升级卡片之间焦点变化可以正常发声。

暂停/后台清空声音，恢复可见不自动继续；显式继续先排除旧事件，再接收新事件。
升级界面丢弃普通战斗噪声并保留成长反馈。退出移除窗口/页面监听，停止节点，关闭上下文。
不支持声音、存储读失败或设置写失败均不能阻断战斗。设置写失败保留本次选择并提示。

设置键 `wanjie-mobile-next:chapter-audio:v1` 与游戏存档分离。
G5 不实例化 ChapterAudio，不增加音频设置；旧入口、结算和存档规则保留。

## 证据边界

规则测试验证声部上限、限频、压低音量、拒绝解锁恢复、销毁与固定种子玩法一致性。
真实 Chrome 观察实际 AudioContext、振荡器和音频波形，并录制其输出。
隐藏事件、敌人耐久、经验与首领登场是测试夹具；浏览器手机尺寸不代表实体 iPhone。
音频是否具有足够打击感、危险音是否易懂、扬声器及耳机实际响度，仍需真机与玩家试听。
