# R2-F08 — `reaper`（无间修罗 H012）四压力场景行为验证

**结论：零生产改动。** 加 1 条 `SPECS` + 2 个 `describe`（6 测试）+ 1 个**缺省关闭**的仪器开关
（`RunOpts.dodge`）。`Outcome` **没有长键** ⇒ 七份旧报告用**直接 md5** 复核，逐位相同。

`reaper` 是 H012 四形态里**最后一个**，也是**首个把「闪避」写进 kit 的形态**（`afterDodge`，二阶）。
它逼出了本 harness 与浏览器机器人同构性的**第五个缺口**——机器人**会闪避**，而 `run()` 从来
没按过那个键。补上之后，本片最重要的发现是：**那个缺口在这四个场景里根本补不上**（§5.1）。

### 第 14 条展开：为什么「够不着」（本片的核心）

`run()` 只按 `skill` 与 `ultimate`（外加本片新加的 `dodge`）。而**闪避在机器人那里是反应式的**，
所以「够不着」不是一个开关的开关问题，而是**场景里有没有 cue** 的问题：

- 场景里的 Boss 是 `scenarios.boss` 在 `sim.time = 270` 时**当场新生的**（`FirstBoss:34/41`），
  所以它第一次出手要等一整个 `castCd = 1.7 × bossCastCooldown = 1.7 × 14.31 = **24.33s**`
  （`FirstBoss:41/67`，`threatV2.json:14`）。
- 四个场景**都是** `FRAMES = 600` = **10s**。
- ⇒ 场景里 `boss.next` **永远变不成 cue**，`bossCasts` 实测 **0**（八片全 0，见 §4.3），
  机器人的闪避规则**一次都不触发**。

所以：**把 `dodge` 开关打开，在四个场景里也是死的。** 这是「缺口补不上」而不是「缺口没补」。
本片因此把 `dodge` 做成**忠于机器人**的开关（cue 驱动），并且**断言它在八格里恒为 0**——
把「够不着」写进证据，而不是留成一个缺席的断言。真正的行为测量放到 30s 窗口（§3.2）。

## 5. 发现

### 5.1 「闪避写进 kit」这件事，在四个场景里**测不到**（本片主要发现）

不是 harness 少按了一个键，而是**机器人的闪避是反应式的、而场景里没有 cue**：新生的场景 Boss
第一次出手在 `1.7 × 14.31 = 24.33s`，四个场景都是 10s。⇒ `boss.next` 永不变成 cue，
`bossCasts` 实测 0，闪避规则一次都不触发。

补法有二，本片都做了，并且把两者的差别**写在测试名和注释里**：
1. **身份块**直接调 `sim.action('dodge')` —— 这是**可达**的，量出影刃的形状（3 道 / `pierce 2` /
   满攻 / 仅二阶）；
2. **30s 窗口**（§3.2）跑**机器人自己的规则** —— 量出它在真场景里值多少（515.39 伤害 +
   141.55 血）。

⇒ 教训与 R2-F07 §6o 同源但更进一步：**「读数非 0」和「读数够得着」是两件事，而
「开关存在」和「开关能触发」也是两件事。**

### 5.2 觉醒在**三格**里一分钱不值，在**一格**里值 +21.57%

敌群 / 远程 / 精英三格的 `dealtBy` 两阶**逐位相同**，原因是同一个：**目标在第五个分身第一次
tick（`tick = .12 * i`）之前就死光了**，`nearest()` 返回空 ⇒ 多出来的那个分身无事可做。
而敌群格的 `summonsPeak` **确实**从 4 升到 5 ⇒ **分身真的被召出来了**，只是没有东西可打。

首领格是唯一的例外：`kitDealt` 13564.84 → 16490.48（**+21.57%**），而且**全部来自普攻**——
`basicDealt` 4329.32 / 3092.37 = **1.4000**，正好是 `2.1 / 1.5`（弧从 `1.4π` 变成 `2π` 双斩）。

### 5.3 本 kit 是全系列**唯一**会「把突进送进体接触」的近战 kit 之一（另一个是 F04）

`dashLength` 是恒等函数、`dash(150)` 不读 rank ⇒ 90px 站位每次都落到 Boss 另一侧 60px，
**每一阶都吃同一笔 32.69**（`taken` 两阶逐位相同、`hpMin` 也逐位相同）。
这不是 bug，是「突进型 kit 的定价」，但值得记：**它的觉醒对生存一分钱不加。**

### 5.4 首领格在测一个「10 秒内不出手的 Boss」（全系列，非本片）

`bossCasts = 0` 在**八片**里都成立。首领格因此只量到 **体接触**（F04/F08）或 **零**（其余六片），
从来没有量到「kit vs Boss 的一招」。R2-F07 的文档把这件事写成自己那一格的注脚；八片对齐之后
可以确定它是**仪器性质**，不是某一形态的性质。⇒ 入队（§9）。

### 5.5 `H012_E` 在远程格是 0，但在敌群/精英格不是 —— 半径问题换了个方向

R2-F07 的发现是「一阶技能半径 110 < 敌群环 120 ⇒ 整格打空」。`reaper` 的技能半径 150/160 **够**，
但它把玩家**先推走 150px**，所以 520px 线依然够不到（§4.1），而 120px 环与 120px 精英**够得到**
（`H012_E` = 1889.78 / 635.65）。⇒ **同一个「突进」既扩大了对近身目标的覆盖，也把自己送离了
远目标**；这两件事在同一个数字里。
