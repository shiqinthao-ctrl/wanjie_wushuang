### 行为逐条

1. **普攻 = 霜环**：单测里 8 只 @110px 被一次 `basic()` 全部打伤**并全部被减速**（`chilledUntil = time + 1.2`）；
   rank 1 打不到 124px、rank 2 打不到 149px，且**减速半径 = 伤害半径**（圈外那只既不掉血也不被减速）。
2. **技能 = 随身寒域**：半径 160/200、持续 3s/5s、`follow === true`、`chill === 1.2`；移动玩家后寒域坐标逐位跟随。
3. **寒域会反复续减速**：站桩 2.9s 后假人**仍在减速中**（`chilledUntil - time > 0.9`）—— 单次霜环只给 1.2s，做不到这一点。
4. **减速是 45% 真减速**：先把目标冻在寒域里，再把它挪到 400px（寒域 r=160 够不到、无法续），
   量它 1 秒内接近的距离。对照组每帧清 `chilledUntil`。**比值实测落在 0.45–0.65 区间**（`enemyAI` 的 `× .55`）。

### 觉醒在 Boss 格**真的有效**

bulwark 的觉醒只动护盾上限与火域半径（四场景数字逐位不变）；frostlord 的觉醒**在 Boss 格多打出 15%**：
寒域从 3s 变 5s，10 秒窗口内两次施放 ⇒ **2454.07 → 2821.09（+14.95%）**。已钉成断言。

## 5. 两条规则发现（都进队列，不在本切片改）

### 5.1 霜环只减速**它没打死**的敌人，寒域连打死的也减速

`frost()`（`EvolutionCombat.ts:139-143`）是**先 `explosion`、后遍历 `s.enemies` 设 `chilledUntil`**，
而 `hit()` 在敌人死亡时把它从 `sim.enemies` **splice 掉**（`CombatSimulation.ts:237`）：

```ts
s.explosion(id, point, radius, damage);                       // 打死的已被 splice 出数组
for (const enemy of s.enemies) if (...) enemy.chilledUntil = ...  // ⇒ 只看得见幸存者
```

而 `updateFields()`（`:479-481`）**先 `filter` 成快照再遍历**，所以**打死它的那一跳照样给它上减速**。
两条路径的次序不同，结果就不同：

| | 被一击打死的敌人 | 幸存的敌人 |
|---|---|---|
| `frost()`（普攻 / 必杀） | **不被减速** | 被减速 |
| `updateFields()`（寒域） | **被减速** | 被减速 |

**设计后果**：对一个能被霜环一击清掉的敌群，**霜环的减速完全不生效**（减速只能落在幸存者身上），
所以「霜环减速敌群」这句文案对**弱敌**是空的，只在**打不死的目标**上有意义 —— 而首领免疫减速。
实测印证：敌群格 `曾减速 12/12` 全部来自**寒域**，`basicDealt = 0`（普攻一次都没挥出）。
**这是冻结的遗留次序，只测量、不改**（改它要动 `frost()`，属平衡/规则变更，需独立切片）。

### 5.2 首领免疫减速是**数据结构**给的，不是规则写的

`frost()` 与 `updateFields()` 都只遍历 `sim.enemies`，Boss 是 `sim.boss`（独立对象）
⇒ 全库**没有任何一行**「Boss 免疫减速」的判断。文案（`skillDetails.G2_FROST`：首领免疫减速）与实现一致，
但它是**副作用**而非契约：任何一次「把 Boss 也塞进 `sim.enemies`」的重构都会静默破坏它。
仪器里已把它钉成**可证伪**的断言 —— 同一发霜环下，**旁边 110px 的普通敌人被减速，Boss 不**。
