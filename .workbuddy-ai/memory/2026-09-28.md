**`lightning(id, count, damage, range)`（`:163`）的选目标规则（逐字）**：

```ts
const remaining = [...s.enemies, ...(s.boss ? [s.boss] : [])]; let from: Point = s.player;
const path: Point[] = [{ x: from.x, y: from.y }];
for (let i = 0; i < Math.min(10, count); i++) {
  remaining.sort((a, b) => distance(a, from) - distance(b, from)); const target = remaining.shift();
  if (!target || distance(target, from) > (i === 0 ? 480 : 220) * range) break;
  path.push({ x: target.x, y: target.y }); this.lightningHit(id, target, damage); from = target;
}
s.lightningPath(path, id);
```

1. **从 `player` 出发**（不是从上一个落点以外的任何东西）；
2. 每跳把**剩余池按到当前 `from` 的距离升序排序**，`shift()` 取最近的一个 ⇒ **已命中的目标被移出池，不会二次命中**；
3. **跳距上限是 `i === 0 ? 480 : 220`**（× `range`，这里恒 1）⇒ 首跳 480px、后续 220px；
4. 超过上限就 `break` ⇒ **链断在那里**（不是跳过该目标继续找）；
5. `Math.min(10, count)` 把跳数封顶 10；`from` 更新为刚落点 ⇒ 链是**贪心最近邻**。
6. `lightningHit`（`:147`）：Boss 走 `hitBoss(damage, id, true)`；普通敌人走 `hit(enemy, damage * bonus, id, false, true)`，
   `bonus = superconduct 羁绊 && (enemy.chilledUntil > time) ? 1.35 : 1`。**注意 `superconduct` 不检查元素**
   （与 `thermalshock` 的 `sourceElement === 'fire'` 不同）⇒ 它是「对被减速敌人的**所有雷击** ×1.35」。
7. `lightningArea`（`:157`）：遍历 `[...s.enemies]` 快照，半径内每个 `lightningHit`；Boss 用 `radius + boss.r`。
