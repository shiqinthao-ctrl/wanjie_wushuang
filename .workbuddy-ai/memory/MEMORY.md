## 前提核实（「它没做」类结论）

- **一个函数「返回 false」≠「什么都没发生」** ⇒ 先读调用方是否兜底：`EvolutionCombat.cast` 对未选路的 `A011` 返回 `false`，而 `CombatSimulation.cast:372` 是 `if (journeyCombat?.cast(id)) return;` ⇒ **落回遗留分支照常施放**。我据此把「未选路 ⇒ 不施放」写进记忆，错了一整片。**任何「它没做」，都要在调用方那一行再确认一次。**
- **TASK/队列的「做法」与「理由」都可能为假** ⇒ **必翻遗留 oracle**（`baseline/*-oracle.json` = V3.1.3 真行为），先当假设测一遍。前提为假 ⇒ 零生产改动，交付「测量 + 归因 + 写回队列」。
- **「没有格包含它」可能是断言不是遗漏** ⇒ 动任何 `scenarios.*` 前先 `grep` 整套 harness 里针对那个场景的断言（「首领格不撒小怪」实为 `R2-F-INST:3040` 的十形态共用断言 ⇒ 塞小怪**必然打红 ×10**）。
- **一个字段「声明在表里」≠「它出场」≠「它被实现」**：`EN004..EN006` 声明 `map:'ST001'` 却**不在任何波次**，且 `charge`/`aoe_ranged` **生产里零读者**（与 `melee` 逐帧相同）。**数集合要分三层数：声明 / 出场 / 有读者** —— 队列把三层写成了一个数字。
- **「没有验收」要按条数一遍**：队列说八条都没有，实测**六条早就有**。**形状差别是「存在性 vs 系数」**（`damageBy.X > 0` 在系数被改时**保持绿**）⇒ 只补缺的那一半，别重写既有的。
- **一个键名可能有多个发射点** ⇒ 先 `grep` 发射点再解释它（`H001_E` 同时由 `CombatSimulation:292` 与 `EvolutionCombat:79` 发出，后者只在**英雄未进化**时触发）。**一个被判定字段也可能没有读者**（`report.g4` 全库只有 `:1764` 读 `.required`）。**注释的归因也可能是错的**（`bossThreat.test.ts:249` 声称靠 `(skillIndex+phase-1)%3`，实际只靠 `+1%3`）⇒ 解释一条性质前先找**最小充分条件**。
- **`filter(x > 0)` 让零命中静默消失** ⇒ 取极值前先问**被滤掉的是什么**（G4 三招两招 0 命中 ⇒ 只剩 1 行 ⇒ `cheapestMove === heaviestMove`，行里没有字段说丢了一行）。**占位 `0` 不是读数** ⇒ 喂 `min` 会造出**假区间 `[0, 0.2206]`**；正确做法是**保留行 + 报 `hits: 0`** 或**断言过滤器移除了哪几行**。
- **`undefined === 0` 是假，而且两个错读数会互相印证。** 未拥有的技能在记录里是**不存在**不是 0 ⇒ 第一版 `unlock` 判据在 **600 局**上写出 `unlocks: 0`，**与 `slotSaturated: 0` 正好互相支持**，长得完全像结论（真值 22.7/22.5/24.7%）。**两个错读数互相印证比一个更危险** ⇒ 任何「字段 == 0」的计数，先确认「没发生」时是 `0` 还是 `undefined`。

## 仪器

- **同构** `settlement.spec.ts` 机器人（180ms 按 e/r/f + 闪避）；**测 kit 自己按技能并关宠物**。**弱驱动 = 另一个玩家**；**按技能键是两件事**（也跑 `releaseManual()`）⇒ 先枚举共享状态。
- **驱动函数要对**：`enemyAI` 与 `updateEnemyWarnings` 在 **`beginFrame`** 里跑，**不在 `updateOuter`**（后者只跑涡旋/场/弹道，且**不推进 `sim.time`**）。用错驱动会得到**全 0 位移/全 0 间隔**，那**不是**「敌人不动/间隔为零」。`beginFrame` 还跑刷怪与普攻 ⇒ 探针要 `atk = 0` + 每帧清掉刷出来的敌人。
- **归一化位移**（`移动量 / (speed·dt)`）= `enemyAI` 选的 `move` 乘数，不同速度的敌人可直接比；「没有冲刺」按**每帧步长完全相同**断言，不是按总和。
- **周期量按帧读**：在每次触发时**复位到常量**，复位间隔就是周期；「间隔是常量」正是「不自我叠加」的判据。
- **一个「把全部 X 清零」的循环可能遍历零项**：`cool` 初始是 `{}`（`CombatSimulation:79`）⇒ `for (const id of Object.keys(sim.cool))` 体一次都不执行，自动施法读到 `undefined`（`!(undefined > 0)` 为**真**）⇒ **第一帧放光所有已拥有技能**。症状像被测代码错（多一个涡旋、两个假人同时被冻住），其实是**夹具没生效**。**修法**：按 `Object.keys(snapshot().skills)` 置大数；**判据**：夹具里任何 `for (…Object.keys(state))` 先断言它非空。
- **判别量用 kit 账本字段**；先拆 `dealtBy`（聚合在负结果格骗人）；**可达性 ≠ 伤害**；空间主张用「移动后读坐标」；**字段全 0 = 没发生或没被记 —— 看那个 `if`**。
- **「开关存在」≠「能触发」**：为 0 的开关比没有更糟。断言默认窗口恒 0 + 真测量另开**显式窗口**。**窗口长度决定可见性**：节奏驱动的事件到不了就拉长（从配置读、按场景覆写）或写成已知边界。
- **对照臂的源 id 必须与生产同元素**：自造 `CTRL` 会被 `sourceElement` 判成 **physical** 而生产是 **fire**，元素本身在 `damageMultiplier` 里 ⇒ 假差异 **1.67×**。**单开关控制 = 同一个量、同一条管线、同一个元素，只让被测系数变。**
- **重块要显式超时**，但**判据不是「它慢」而是「它的墙钟依赖邻居」**（`formPressure.test.ts:3294` 单独 3.11s 绿、全量超 5s = 并行争抢；`skillCadence` 的种子扫描单独 3.0s、全量 7.8s）。**修法两条**：① **记忆化**（`cached ??= build()`）② **显式超时**（照抄同文件惯例）。只加超时会在块数增长时重淹，只记忆化会在单块变重时重淹。**两个 `it` 各自冷跑同一批 = 双倍开销** ⇒ 合并 + 记忆化。
- **调 `validOptions()` 会扰动它正在测的那一局**（它用本局 RNG 洗牌）⇒ 可选数由快照**重算**，再用 `shown === min(3, eligible)` 交叉验证，让推导**可被证伪**。
- **保真度驱动，不由通过数驱动**；红可以是设计信号；**改仪器作废早期标定 ⇒ 显式入队**；两 harness 同口径；会写文件的 harness 赋值在断言前；报告测试排最后。
- **首轮报出的红是下限，不是全量**：同一个 `it` 里前一条红了，后面的**根本不会跑**。D23 首轮 13 条，复跑又露出 2 条 ⇒ **红的总数按「复跑到全绿」数**。

## 读数与统计

- **「读数是一个连续量」是最贵的默认假设**：先问**最小增量**与**单位**。`taken` 看着像伤害总量，实为**命中次数 × 单次接触伤害**（320 样本全落在 `11.52*(1-14/74) = 9.34054…` 的整数倍上）⇒ **离散量不给中间档**，只能交付**那张表**。
- **「扫描床上恒定」是要测的断言**：控制臂实测**不恒定**（`reaper` `DDCCCDCC`）。**非连续的结果集 = 测的不是距离**（距离给区间、竞态给点集）⇒ 那是「这不是距离阈值」的**证明**，不是数据脏。
- **「既有仪器覆盖它」要分臂数一遍、再分轴数一遍**：队列说「带上没有对应物」**一半是假的** —— kit 臂早有 `radiusSweep()`（已断言 `[120]` 唯一），缺的只有**控制臂**。
- **结局量混沌**：单种子 A/B、n=11 不可用；平衡数字 ≥ **33 种子**；胜率**必须带仪器声明**；**聚合掩盖反向 cell ⇒ 分路线报**。
- 份额从 `damageBy` 的 source 分类，**划分完备**；**先筛前缀**（兜底会吞无关来源），**排除共享前缀的兄弟键**。
- **反事实按事件顺序重放**（非终态集合）；**定格参数从 `raw` 反解且比较取整值**；**反事实要钉实测值，不要钉阈值**（`[61,58]` 而不是 `moved > 0.9*total`）。
- **分母不是常数** ⇒ 观测集合断言在区间内且 ≥2 值；**归因条件逐字抄生产**；**边界写清包含/排除**。
- **「两个读数不同」先问「是不是子集」**：子集关系直接点名**哪一半被漏掉**（GDD 的 G8 字面两键 ⊂ 桶读数，漏掉的正是 `manual` 判 `true` 的那一半 = 指标存在的理由）。
- **判「哪个口径才对」用「两个读数是否朝同一方向动」**：反向 ⇒ 测的是**别的东西**（`r(进化数, gddShare)` = **−0.32** vs `r(进化数, manualCoreShare)` = **+0.34**）。**一个随玩家变强而下降的「贡献」读数，测的不是贡献。** 裁定按**意图**，并把**保守界**记进账 —— **口径不能在两种读法之间来回挑**。

## 判定 / 取舍

- **承诺写成「原来的 / 普通的 X%」时，那个「原来」是一个生产分支** ⇒ **基线必须在同一上下文里现测**（`A011` 的未选路基线随 `m.evo` 改变身份 1 发 → 3 发）。且**「单发正确」≠「总量正确」**：`volley` 单发 65% 恒成立，总量在进化后只有基线的 **65%**（`nova` **48.3%**）⇒ 两个都要报。
- **「有效」≠「修好了」**：候选修法逐条写清「机制生效」与「净额变好」，净额符号用**同一份账本**回答。
- **「两个读数各自正确、基准不同」** ⇒ **先标基准，「TASK 写错」是最后一种可能**；**扫掠下同步翻转的两个读数 = 同一事实的两面 ⇒ 出路是换场地不是换数值**；**一个杠杆同时改两个验收且方向相反 ⇒ 按策略拆开报**。
- **「A 就是 B」的等号要被测量**；**「几何理由」先确认两个量是否同源**（「站位 90 > 半径 70」把「到 Boss 的距离」当成「到圆心」，而圆心 = 玩家 ⇒ `distAtCast` 恒 0）⇒ 写成可判定的不等式并逐格对账（模型解释 46/46 才算结论）。
- **「到达」≠「命中」**（`.75×` 下 `hud` 命中 0 但到达 8 次）；**「没观测到」可能是节奏而非结构** ⇒ 宣布不可测前先把**所有已有的臂**跑一遍。
- **「这个 kit 如此」与「系列如此」分开写**（n=40 曾证伪）。**觉醒要「看得见」就得动第 0 帧的离散量**（跳数/跨环半径）；半径+时长类改动在离散环上可能是第 0 帧中性的。
- **一个旋钮渗进正交维度 = 顺序成了另一个变量的函数**：相位是**难度**旋钮，把它**加进招式下标** ⇒ 顺序随**血量**(=DPS)。**判据不是「它有没有用」而是「它作用在哪个维度」**：拿掉相位项，「相邻两刀永不重招」依然成立 ⇒ **相位项没有防守对象**。
- **「互斥 / 不可能 / 永远」是先验，不是测量** ⇒ 先把那个集合**数一遍**再逐个跑（敌群格「无伤 ⟺ 两阶不可分」被 **40 格 12 反例**证伪；TASK 的「八个形态」实为 **7 处**）。**「互斥可破」≠「随便挑个数」**。
- **一个读数可对参数非单调**（`clean` 对半径 `[T,T,F,T,F,T,T,T]`）⇒ 单调的钉一个数，**非单调的必须连同那张表一起交付**。
- **离散量上的增益是常数 ⇒ 别找中间档**（恒 +831.28/+1219.21）⇒ 一格要么全盲要么全开；先扫区间确认是常数，再问**占比**（Boss 预算的 0.18%/0.27% ⇒「可验证但不值得落地」）。
- **「四个格覆盖了四种威胁」是清单不是覆盖** ⇒ 数那个集合（四格 × 十形态 = 40，`framesBoth` 恒 0）比读格名有用；`bossPhaseSpawnInterval` 是**乘数不是开关**。
- **优先级也是边界，要断言**：Lv.19 的觉醒**抢占**路线选项（`special(19)` 只返回 `['awaken']`）⇒ 写验收先问「这一档还有谁在抢同一个返回值」。
- **「最弱的那一格」要用同口径数出来**（敌群 7/10 < `ranged` 8/10 < `elite` 9/10）。
- **一条恒等式在一侧为空时不是「更难满足」，而是「不成立」**：空 `kept` 上 `kept[0] === cheapestMove` 拿到 `undefined` vs `0` ⇒ 改成「有 survivor 就比、没有就断言空过滤器自己的产物是 0」。**没有主语的恒等式会让人以为数据脏了。**
- **行号引用会随插入位移** ⇒ 会被引用的文件里加仪器**一律追加到末尾**，并断言「新常量 == 旧构造」。**行号要按 `❯ file:line:col` 读，不能按「附近最像的那条」猜**（D23 因此把 G7 的 `fusionRuns` 误读成 G6 的 `median(evolved)`，错了一轮）。
- **一个 `detail` 可以「单发正确、总量反转」**；**给一个旋钮加字段要 `grep` 消费者**（`skillModifier` 的进化 `count++` 只有 `S001` 一个读者；`m.dmg`/`m.range` 都生效、唯独 `m.count` 不生效 ⇒ 只看总伤害发现不了）。
