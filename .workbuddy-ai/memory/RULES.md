## 前提核实（「它没做」类结论）

- **一个函数「返回 false」≠「什么都没发生」** ⇒ 先读调用方是否兜底（`EvolutionCombat.cast` 返 `false`，而
  `CombatSimulation.cast` 是 `if (journeyCombat?.cast(id)) return;` ⇒ 落回遗留分支照常施放）。
- **TASK/队列的「做法」与「理由」都可能为假** ⇒ 必翻遗留 oracle，先当假设测一遍。前提为假 ⇒ 零生产改动，
  交付「测量 + 归因 + 写回队列」。
- **「没有 X」要先问「X 的防守对象存在吗」**：D24 的「无隐形阻挡」是**空真**（全库零碰撞体）。**空真断言与
  真断言长得一样，但只有后者会在有人加进第一个碰撞体时变红** ⇒ 一律换成强形式（每一步步长完全相同）。
  **「没有格包含它」可能是断言不是遗漏** ⇒ 动 `scenarios.*` 前先 `grep` 整套 harness 对它的断言。
- **一个字段「声明在表里」≠「它出场」≠「它被实现」** ⇒ **数集合分三层数**。同理**「既有仪器覆盖它」要分臂
  数一遍、再分轴数一遍**；**「没有验收」要按条数一遍**（队列说八条都没有，实测六条早就有 ⇒ **形状差别是
  「存在性 vs 系数」**，只补缺的一半）。
- **正则漏 shorthand 会造出「字段没写」的假结论**（`{ runId, stars, … }` 的裸标识符不算 `\w+: …`）。
- **同一个数字在两处有两种态度，而两处都对**：`20` 在写入处 `slice(0,20)`（静默丢最旧）、在校验处 `>20` 抛
  （**拒收整份存档**）⇒ 能假设 `<= 20`，**不能**假设 `=== 20`。**截断与拒收不是同一个的备份。**
- **校验允许的范围可以比写入的宽，宽出来的格子是假的**：`stars` 写 `0/1`、校验允许 `0..3` ⇒ 按校验画三格，
  每次胜利都显示 1/3。**画实际值，不画声明范围。**
- **一个断言把整个字面量钉死就成了摩擦** ⇒ **断言范围应等于它声称的事实范围**；钉自己那一段，不钉邻居。
  **「A 与 B 形状一样」的断言，必须让 A 与 B 在别的维度上真的不同**（失败局沿用胜利局的 `time`，什么都没证明）。
- **一个键名可能有多个发射点** ⇒ 先 `grep` 发射点再解释它。**一个「杠杆」也是**：D30 的 `skillCd` 有三处写入
  （`CombatSimulation`/`DragonCombat`/`EvolutionCombat`），改一处等于对两个英雄无效 ⇒ 收成一个函数三处调用。
  **被判定字段也可能没有读者**（`hazardPeak` 零读写）。**注释的归因也可能是错的** ⇒ 先找**最小充分条件**。
- **`filter(x > 0)` 让零命中静默消失**；**占位 `0` 不是读数**（喂 `min` 会造出假区间）⇒ 保留行 + 报 `hits: 0`。
  **`undefined === 0` 是假，两个错读数会互相印证**（`unlocks: 0` 与 `slotSaturated: 0` 互相支持，真值 22.7%）
  ⇒ 「字段 == 0」的计数先确认「没发生」时是 `0` 还是 `undefined`。
- **读回的字段要先确认它是什么**（`castLog` 记的是 `event.shape` 不是招式名 ⇒ 反事实算出 61/61 是假）⇒ 修法
  不是改数，是把返回「键」与返回「名」拆成两个函数。**反解出来的量不是「遭遇的性质」。**

## 仪器

- **驱动函数要对**：`enemyAI` / `updateEnemyWarnings` 在 **`beginFrame`** 里跑，**不在 `updateOuter`**（后者不推进
  `sim.time`）。用错驱动得到全 0，那**不是**「没发生」。`beginFrame` 还跑刷怪与普攻 ⇒ 探针要 `atk=0` + 每帧清敌人。
- **夹具两次调用共享状态时先问它清的是哪个字段**：`clearInput()` 同时清零平滑输入 `response` ⇒ 「先跑 30 帧
  稳定再另起 sweep」会让第二段第一帧是斜坡起点（3.5167 vs 4.16）⇒ 看起来像**隐形阻挡**。修法：settle 与
  measure 放进同一个循环。
- **归一化位移**（`移动量/(speed·dt)`）= `enemyAI` 选的 `move` 乘数；「没有冲刺」按**每帧步长完全相同**断言。
  **周期量按帧读**：每次触发时复位到常量，复位间隔就是周期；「间隔是常量」正是「不自我叠加」的判据。
- **一个「把全部 X 清零」的循环可能遍历零项**：`cool` 初始是 `{}` ⇒ `Object.keys` 体一次不执行 ⇒ 第一帧放光
  所有技能。**判据**：夹具里任何 `for (…Object.keys(state))` 先断言它非空。
- **同构** `settlement.spec.ts` 机器人；测 kit 自己按技能并关宠物；**弱驱动 = 另一个玩家**；**按技能键是两件
  事**（也跑 `releaseManual()`）⇒ 先枚举共享状态。
- **判别量用 kit 账本字段**；先拆 `dealtBy`；**可达性 ≠ 伤害**；空间主张用「移动后读坐标」；**字段全 0 = 没
  发生或没被记 —— 看那个 `if`**。**「开关存在」≠「能触发」**：为 0 的开关比没有更糟 ⇒ 断言默认窗口恒 0 +
  真测量另开**显式窗口**。
- **对照臂的源 id 必须与生产同元素**（自造 `CTRL` 判成 physical 而生产是 fire ⇒ 假差异 1.67×）。
  **单开关控制 = 同一个量、同一条管线、同一个元素，只让被测系数变。**
- **重块要显式超时**，判据不是「它慢」而是「墙钟依赖邻居」⇒ **记忆化 + 显式超时两条一起上**。
  **调 `validOptions()` 会扰动它正在测的那一局**（用本局 RNG 洗牌）⇒ 可选数由快照重算再交叉验证。
- **保真度驱动**；红可以是设计信号；**改仪器作废早期标定 ⇒ 显式入队**；会写文件的 harness 赋值在断言前。
- **首轮报出的红是下限**（同 `it` 里前一条红了，后面的不跑）；**「首轮全绿」也可能是过期绿**：全量采集在启动
  那一刻，期间改测试文件不会被重读（D27：`01:00:19` 启动、mtime `01:00:33`）。**判据是「mtime 早于采集时刻」**。
  **边跑边改时 mtime 也救不了**（D28 跑到 1m25s 补了第 16 条）⇒ **信号是「进程还活着」**，活着就别改测试文件。

## 读数与统计

- **「读数是一个连续量」是最贵的默认假设**：先问**最小增量**与**单位**（`taken` 看着像伤害总量，实为**命中次数
  × 单次接触伤害**）⇒ **离散量不给中间档**，只能交付那张表；**离散量上的增益是常数 ⇒ 别找中间档**。
- **「扫描床上恒定」是要测的断言**；**非连续的结果集 = 测的不是距离**（那是证明，不是数据脏）。
- **结局量混沌**：平衡数字 ≥ **33 种子**；胜率**必须带仪器声明**；**聚合掩盖反向 cell ⇒ 分路线报**。
  **混沌序列上的 `max` 不要钉值，要钉上界**（D23 钉 `>=1`，D24 回到 0 ⇒ 改 `<=1`）。
- 份额从 `damageBy` 的 source 分类，**划分完备**；**先筛前缀**，**排除共享前缀的兄弟键**。
- **反事实按事件顺序重放**；定格参数从 `raw` 反解且比较取整值；**反事实要钉实测值，不要钉阈值**。
- **分母不是常数** ⇒ 观测集合断言在区间内且 ≥2 值；**归因条件逐字抄生产**；**边界写清包含/排除**。
- **「两个读数不同」先问「是不是子集」**：子集关系直接点名哪一半被漏掉。
- **判「哪个口径才对」用「两个读数是否朝同一方向动」**：反向 ⇒ 测的是别的东西。裁定按**意图**，保守界记进账；
  **口径不能来回挑**。**一个读数可对参数非单调** ⇒ 单调的钉一个数，非单调的**必须连同那张表一起交付**。

## 判定 / 取舍

- **承诺写成「原来的 / 普通的 X%」时，那个「原来」是一个生产分支** ⇒ 基线必须在同一上下文里现测。且
  **「单发正确」≠「总量正确」**（`volley` 单发 65% 恒成立，总量在进化后只有 65%，`nova` 48.3%）⇒ 两个都报。
- **「有效」≠「修好了」**：逐条写清「机制生效」与「净额变好」，净额符号用**同一份账本**回答。
- **「两个读数各自正确、基准不同」** ⇒ 先标基准，「TASK 写错」是最后一种可能；**扫掠下同步翻转的两个读数 =
  同一事实的两面 ⇒ 换场地不是换数值**；**一个杠杆同时改两个验收且方向相反 ⇒ 按策略拆开报**。
- **「A 就是 B」的等号要被测量**；**「几何理由」先确认两个量是否同源**（把「到 Boss 的距离」当成「到圆心」，
  而圆心 = 玩家 ⇒ `distAtCast` 恒 0）⇒ 写成可判定的不等式并逐格对账。
- **「到达」≠「命中」**；**「没观测到」可能是节奏而非结构** ⇒ 宣布不可测前先把**所有已有的臂**跑一遍。
- **「这个 kit 如此」与「系列如此」分开写**（n=40 曾证伪）。**觉醒要「看得见」就得动第 0 帧的离散量**。
- **一个旋钮渗进正交维度 = 顺序成了另一个变量的函数**（相位加进招式下标 ⇒ 顺序随 DPS）。**判据不是「它有没
  有用」而是「它作用在哪个维度」**。**「互斥 / 不可能 / 永远」是先验** ⇒ 先把那个集合**数一遍**再逐个跑。
- **「四个格覆盖了四种威胁」是清单不是覆盖** ⇒ 数集合比读格名有用；`bossPhaseSpawnInterval` 是**乘数不是开关**。
  **优先级也是边界，要断言**（Lv.19 觉醒抢占路线选项 ⇒ 先问「这一档还有谁在抢同一个返回值」）。
- **一条恒等式在一侧为空时不是「更难满足」，而是「不成立」**（空 `kept` 上 `kept[0]===cheapestMove` 拿到
  `undefined` vs `0`）⇒ 改成「有 survivor 就比，没有就断言空过滤器自己的产物是 0」。
- **行号引用会随插入位移** ⇒ 加仪器**一律追加到末尾**；行号按 `❯ file:line:col` 读，不能猜。
- **给一个旋钮加字段要 `grep` 消费者**（`skillModifier` 的 `count++` 只有 `S001` 一个读者）。
- **「缺一个守卫」要先问「有没有可达路径」**：敌人移动一直没 clamp，但后退方向永远指向内侧 ⇒ **几何在替 clamp
  干活**；`charge`（瞄**穿过**玩家）是**第一条**给它造出路径的机制。**新机制会点亮旧缺口** ⇒ 加机制时把它经过
  的每条既有守卫数一遍。**clamp 的是「谁」要说清**：钳**中心**还是钳**身体** ⇒ 前者留下永久免伤区。

## 文档 / 门槛 / 证据

- **门槛写比率或序关系**；**先读注释再读代码**；**复合断言须能从某行数据推出**；「pin every X」要逐项数清单。
- **临时探针必须与正式块一起核**：三种形态（内联 `describe('PROBE')`、`cat >>` 追加、独立 `__probe_*.test.ts`）。
  **定位靠两条同时出现**：`+N ≠ 本片 it 数` **且** `文件数 +1`。防线 `src/core/treeHygiene.test.ts` 已落地。
- **逐字节账要写成可执行清单**：「核对了清单」≠「核对了树」，漏项**不报错只沉默**。修法 = 生成器走树 +
  `byteLedger.test.ts`（独立重算）+ `ledger:verify`。**滚动 vs 冻结必须由源码派生，不能靠 mtime。**
- **「从源码派生」的分类器认字面调用形状**：别名 import、预绑定全路径 const、三参 `resolve`、文件名用常量、
  子目录里的快照全不被识别。**扫描器连注释一起读**。**快照不能放在被扫描的目录里**。
- **schema 长大的 md5 有两个用法不能混**：相等性用「去新键 + `sort_keys` 重建」；覆盖率用**明文直接 md5**。
- **覆盖声明要与数字同句，且由命令产出**。**滚动报告属于当前代码**：迁到当前切片目录、旧目录留指向。
- **数产物要用会看内容的命令**：`git status` 在证据树上**多报 `M`**（只有 CRLF 变化），`git diff --numstat`
  一行都不输出 ⇒ 它答的是「文件有没有被碰过」，不是「内容有没有变」。
- **设计文档里的断言没人执行 ⇒ 最易烂**；**改设计文档是「免费的文档半边」**，先确认门禁不含它。
  **`WORKSHOP-BRIEF.md` 不在上下文包 ⇒ 不被 `context` 提醒**；写「当前/唯一阻塞」的文档切片结束回看。
